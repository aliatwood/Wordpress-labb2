# Laboration 2 – Introduktion till PHP

## Om projektet
Detta projekt är skapat som en del av kursen och handlar om att lära sig grunderna i PHP och databashantering.

Webbplatsen innehåller en personlig bucketlist där användaren kan lägga till, visa och ta bort saker som den vill göra i framtiden.

## Webbplatsens sidor
- **Startsida:** Information om laborationen och reflektioner kring PHP.
- **Bucketlist:** Möjlighet att lägga till, visa och ta bort aktiviteter.
- **AI-sida:** Beskrivning av hur AI har använts under arbetet och vad jag har lärt mig.

## Tekniker
- PHP
- HTML
- CSS
- MySQL/MariaDB
- PDO
- Git och GitHub

## Databas
Projektet använder en MySQL/MariaDB-databas för att lagra bucketlistens aktiviteter.

Tabellen innehåller:
- ID
- Namn
- Beskrivning
- Prioritet
- Skapandedatum

## Installation och körning
1. Installera XAMPP.
2. Starta Apache och MySQL i XAMPP.
3. Lägg projektmappen i `htdocs`.
4. Skapa databasen `bucketlist`.
5. Importera SQL-filen från mappen `database`.
6. Öppna `http://localhost/Wordpress-labb2/` i webbläsaren.

## Reflektion
Under arbetet har jag lärt mig mer om PHP, objektorienterad programmering och hur PHP kommunicerar med en databas. Jag har även fått öva på att felsöka kod och använda GitHub för versionshantering.
